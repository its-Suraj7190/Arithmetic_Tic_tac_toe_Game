# 🔢  Project Overview :
Arithmetic Tic-Tac-Toe is a mathematical strategy game that extends the traditional Tic-Tac-Toe experience by incorporating arithmetic concepts and numerical decision-making. The project combines game development, object-oriented programming, and mathematical analysis to create a unique gameplay experience. Players must strategically select and place numbers while attempting to form winning arithmetic combinations.

# ✨ Features :
* One gameplay modes:
  * Player vs Player
* Object-Oriented Programming (OOP) based design
* Arithmetic Progession Mathematical mechanism based game winning - line evaluation system
* Custom winning condition generation using derived equations.
- Scalable game design supporting different board sizes and rule variations.
